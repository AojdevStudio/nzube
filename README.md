# Nzube

**Your intent, ready for your agent.**

Nzube is being built to turn rough intent into complete execution briefs grounded in selected guidance, attachments, and permitted repository evidence. It prepares the work for your agent; it does not execute repository changes or dispatch agents.

The product is in feasibility development. There is no released application yet. macOS, Windows, Linux, iOS, and Android are targets, not verified availability claims. Provider subscription support and mobile authentication require real integration proof.
