# Bundled guidance

`general.md` is original Nzube guidance, covered by the repository's Apache-2.0 license. It is an optional organizational aid; application policy and the user's intent remain authoritative.

User-provided workflow methods, model guidance, language references, and project conventions belong in the imported library. Files supplied during development are not included here and have not been approved for redistribution. PStack is configurable user guidance, not a hard-coded dependency of the default brief.
